## 2. Source algorithms (read pinned comparable Minecraft 1.21.1, not patched NeoForge compiled bodies)

Pinned public comparable revision [`b77c5c6995874f6cf2755bc5234428906b337b75`](https://github.com/hackersense/OptiFine-Source/tree/b77c5c6995874f6cf2755bc5234428906b337b75/1.21.1).

[`CoralBlock`](https://github.com/hackersense/OptiFine-Source/blob/b77c5c6995874f6cf2755bc5234428906b337b75/1.21.1/net/minecraft/world/level/block/CoralBlock.java#L34-L86): `getStateForPlacement` and `updateShape` call `scanForWater` across **six physical neighbor FluidStates**, excluding own cell. If no physical adjacent WATER, schedule block tick **60 + random.nextInt(40) => 60..99**; `tick` checks six neighbors again and when still dry replaces source with the matching `deadBlock.defaultBlockState()` (no WATERLOGGED). If water returned, scheduled tick performs no conversion. This uses real physical 3D adjacency, **not six face-local tangents**, and is independent of `BaseCoralPlantTypeBlock`.

[`BaseCoralPlantTypeBlock`](https://github.com/hackersense/OptiFine-Source/blob/b77c5c6995874f6cf2755bc5234428906b337b75/1.21.1/net/minecraft/world/level/block/BaseCoralPlantTypeBlock.java#L22-L108): `defaultState.WATERLOGGED=true`, `getStateForPlacement` checks actual target FluidState water with **getAmount()==8**, not just nearby water; `getFluidState` returns water source only if WATERLOGGED. Common `scanForWater` returns **true immediately if own WATERLOGGED=true**; otherwise scans six physical neighboring FluidStates for FluidTags.WATER; thus a waterlogged live plant may survive even when all neighbors dry, while dry+isolated plant schedules death. Base `tryScheduleDieTick` schedules **60..99** ticks when no own/neighbor WATER. `canSurvive` requires support **physical pos.below()** with actual source-facing `Direction.UP isFaceSturdy`; `updateShape` schedules water tick if WATERLOGGED and removes to AIR when updated neighbor side is physical DOWN and support invalid.

[`CoralPlantBlock`](https://github.com/hackersense/OptiFine-Source/blob/b77c5c6995874f6cf2755bc5234428906b337b75/1.21.1/net/minecraft/world/level/block/CoralPlantBlock.java#L19-L80) and [`CoralFanBlock`](https://github.com/hackersense/OptiFine-Source/blob/b77c5c6995874f6cf2755bc5234428906b337b75/1.21.1/net/minecraft/world/level/block/CoralFanBlock.java#L16-L69): `onPlace` schedules death if dry; `updateShape` checks DOWN support, if unsupported AIR; else schedules death if dry, water fluid tick if WATERLOGGED, then super. Their `tick` turns live into dead matching type **with WATERLOGGED=false** when no own/adjacent WATER (not `copyProperties`); near support death must preserve correct species, and base dead default block validity needs separate proof. Dead floor plant/fan inherit support+fluid tick but **have no scheduled die tick** of their own. Their physical AABBs differ (plant tall, fan thin), Phase 3.

[`BaseCoralWallFanBlock`](https://github.com/hackersense/OptiFine-Source/blob/b77c5c6995874f6cf2755bc5234428906b337b75/1.21.1/net/minecraft/world/level/block/BaseCoralWallFanBlock.java#L22-L119): wall `FACING` is horizontal 4 legal values, own getStateForPlacement attempts nearest directions + support, own canSurvive behind FACING; `updateShape` removes only on opposite-side update when support missing, enqueues water tick if WATERLOGGED, otherwise returns state, and does **NOT** invoke super; distinct from generic floor support. `rotate/mirror` and `getShape` depend on FACING; source and target canonical frames at seam must be distinct. [`CoralWallFanBlock`](https://github.com/hackersense/OptiFine-Source/blob/b77c5c6995874f6cf2755bc5234428906b337b75/1.21.1/net/minecraft/world/level/block/CoralWallFanBlock.java#L16-L71) onPlace/tick/updateShape add death scheduling and WATERLOGGED fluid schedule; dry death changes to **matching dead wall fan** keeping exact old FACING, forces WATERLOGGED=false.
