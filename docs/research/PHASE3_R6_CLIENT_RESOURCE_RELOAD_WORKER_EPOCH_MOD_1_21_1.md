## 2/4 — Source context/epoch model and negative contracts

There are three distinct lifetimes, which the Planet shared adapter must never collapse:

1. **World epoch:** source world `Level` object, dimension/connection identity, `Minecraft.setLevel` and `LevelRenderer.setLevel`. Stale world-dependent block-frame/position lookup from previous world must not be evaluated against the current `Minecraft.getInstance().level`; the same numerical `BlockPos` may exist in a completely different world. Source `BlockGetter`/RenderChunkRegion/virtual `Level` may be separately scoped.
2. **Section-worker epoch:** `SectionRenderDispatcher$RenderSection$CompileTask`, captured sectionOrigin/Level, ModelData snapshot, `SectionCompiler.compile`, deferred `AdditionalSectionRenderer.render(context)`. Pending task cancellation is **cooperative**, `blockUntilClear` not a full join, `dispose` may process queued uploads. A mod callback can outlive the selection of a new world unless the actual published resource/work token is checked. **This is a risk and future contract, not a demonstrated Planet stale render bug.** `AddSectionGeometryEvent.getLevel` source-call on main thread vs `SectionRenderingContext.getRegion` worker accessor must remain distinct.
3. **Resource/model/GPU generation:** vanilla `ModelManager` and `TextureManager` are resource reload listeners; BER `BlockEntityRenderDispatcher` rebuilds renderer instances on resource reload; Create/Flywheel instantiated models/materials and shaderpack atlas/normal buffers can have their *own* resource/generation lifetimes. No evidence that a `Level` identity alone correctly keys all model/atlas/buffer caches. Handle source-world identity **and** current resource generation, and don't reach for a global `PoseStack`/shader normal proxy.

**Safe future contract (not implemented in this source-only packet):** Capture explicit origin `Level`/region/section, canonical local frame and physical light semantics with immutable epoch token; never assume a callback retains a live main client level or that a canceled task cannot continue. On world switch, section invalidation or reload, only publish the source-correct render result if its token still matches; dispose/retire any independent cached GPU instance *after* appropriate backend barrier. In fake world/noLevel GUI preserve vanilla behavior unless a valid source frame is proven. Cache keys must include all dynamic source dependencies; `BlockState`-only occlusion/culling can be incorrect when BlockEntity, world or epoch matters. This is an implementation hypothesis/requirement, **not an assertion existing Planet code does so**.
