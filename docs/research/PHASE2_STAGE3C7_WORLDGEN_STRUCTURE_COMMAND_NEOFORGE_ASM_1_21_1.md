## 2/4 — full writer transaction, BE/fluids/survival and bypasses

**Structure stages must stay ordered:** select palette using origin/RNG; NeoForge block processor pipeline; transform positional mirror/rotation in `StructurePlaceSettings` around physical pivot; validate physical `BoundingBox`; capture source fluids; if BE payload exists, clear existing BE, insert temporary BARRIER flag20; commit final BlockState using passed flags; rehydrate new BE `loadWithComponents` and LootTableSeed; if apply-waterlogging, use `LiquidBlockContainer.placeLiquid` and source fluid restoration; after writes perform optional `updateShapeAtEdge` via physical `DiscreteVoxelShape.forAllFaces`, neighbor connection repair `Block.updateFromNeighbourShapes` then `blockUpdated`, final BE `setChanged`; spawn entities via NeoForge processor-aware path. A translated or early-return Mixin skipping one stage can break mod inventory, attachments, vanilla redstone, water and processors.

**Worldgen:** `WorldGenRegion` is a physically scoped **generation facade**, not a subclass of `Level`. Its `setBlock` uses `ChunkAccess` with delayed BE metadata; `WorldGenLevel.ensureCanWrite` must stay valid for original window and early/late chunk lifecycle. `ProtoChunk` pending `DUMMY` NBT is intentionally not an immediately ticking full BE. Direct `ChunkGenerator.fillFromNoise` and `ChunkAccess.setBlockState` bypass both `LevelMixin` and `BlockItem` entirely; don't force `Level#setBlock` here or initialize BEs prematurely. `LevelAccessor` methods route scheduled ticks via `LevelTickAccess` during generation, not necessarily the runtime ServerLevel queue, and fluid tick semantics remain separate (2.3C-5).

**Commands:** `BlockInput.place` performs dynamic support connection adjustment **before writing**, and BE NBT restore afterward. `/setblock` destroys vs clears BE depending on mode, `/fill` enforces bounded volume, `/clone` copies scheduled block ticks and BE components, not just BlockState; these paths may pass typed command-author state without a player. Coordinates are world physical and must not be silently retargeted to another chart. Mod commands/editors/schematic tools can call direct `LevelWriter`, `ChunkAccess` or entirely separate code; inheritance from vanilla command is NOT guaranteed.

**Modded structure processors:** NeoForge processors can replace or omit BlockState, and process entities and BlockEntity metadata; the shared boundary is a **processor-preserving structure plan with physical destinations and separately transported local/canonical properties**, not an override of `BlockPos.relative`, `Level.setBlock`, or `StructureTemplate` internals for all worlds. `StructurePlaceSettings.knownShape`, mirror/rotation/pivot, bounding box, fluid settings and entity-finalization settings are **semantic input**, not generic flags.

**Survival / delayed updates:** `updateShapeAtEdge` and `Block.updateFromNeighbourShapes` see updated physical neighbors in multiple steps; no guarantee that independently adapted local FACE frames form a valid rigid whole at a seam. Must preserve versioned support rules, ownership/replacement semantics, BE ticking/persistence from 2.3C-6 and Forge/NeoForge event ordering from 2.3C-4.

## 3/4 — deepest SAFE shared boundary and mod extension matrix

| Subsystem | Disposition | Correct boundary |
| --- | --- | --- |
| Physical `BlockPos`, `ChunkPos`, structure `BoundingBox`, mutable XYZ, `WorldGenRegion` write-radius, `ChunkAccess`, raw `LevelWriter.setBlock` | **PHYSICAL_DO_NOT_TOUCH** | Required by structures, mod features, worldgen threads, chunk persistence and fake Levels |
| Multiple actual writer implementations (`Level`, `WorldGenRegion`, `ChunkAccess`, commands) | **SHARED_SAFE observation** | Typed provenance: `WORLDGEN_FEATURE/CHUNKGEN/STRUCTURE/COMMAND/PLAYER/FOREIGN`, physical source+target and stage; no implicit gravity transformation |
| Planet local gravity relative orientation of **feature/structure algorithms** | **OPT_IN_ALGORITHM** | Chart-local sampling and property transform with explicit preserved physical destination; whole rigid structures choose edge policy BEFORE side effects |
| `StructureProcessor.process`, NeoForge full template arg, custom BE NBT, scheduled ticks, fake Levels and mod commands | **MOD_INDEPENDENT / PHYSICAL by default** | Retain mod processor list & ordering and original API callbacks; unknown writer stays physical |
| Client entity/render orientation or BE renderer | **CLIENT/RENDER** | Separate render acceptance; do not embed it in server placement adapter |

**Deepest safe adapter design only (NO runtime API added)**: `PlanetWorldWriteIntent` holds author, source `LevelAccessor` type (real/fake/generation), real physical input `BlockPos` and immutable target, optional chart/frame for local meaning, full BlockState/canonical transform, explicit `flags/recursionLeft`, feature/structure RNG+processor context, BE/fluids metadata, and acceptance ownership. Thin 21.1.1/NeoForge adapters route at proven owner-specific injection boundaries. **One level deeper unsafe:** changing generic `ChunkAccess.setBlockState`, `LevelWriter.setBlock`, `BlockPos` or `Direction` would modify all modded physical worlds. **One level shallower incomplete:** only `LevelMixin` catches runtime Level writes, missing generation, structures and command transaction order. Real pinned 1.21.1 mod source comparators and code owners are referenced in existing [worldgen/structure research](ENVIRONMENT_WORLDGEN_STRUCTURE_COMPAT_MATRIX_1_21_1.md) and [portal/structure mod source audit](PHASE2_STAGE3A_PORTAL_STRUCTURE_BE_MOD_SOURCE_OWNER_AUDIT_1_21_1.md); loaded jars not executed.
