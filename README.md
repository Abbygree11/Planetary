# Planetary

NeoForge-мод для Minecraft 1.21.1 с конечным миром в форме кубического планетоида.

## Текущее направление

Начиная с 2.0 проект уходит от сферического PoC 1.x и строится вокруг кубической планеты:

- 6 граней, у каждой собственные local UP/DOWN/NORTH/SOUTH/EAST/WEST;
- local DOWN всегда направлен к ядру соответствующей грани;
- при переходе через ребро локальная система координат поворачивается на 90°;
- блоки остаются обычными Minecraft `BlockState` с обычными моделями, `VoxelShape`, hardness, loot, звуками, жидкостями, redstone и block entities;
- рендер поворачивает готовые vanilla `BakedQuad`, не меняя UV;
- мир загружается трёхмерно секциями 16×16×16 вокруг игрока;
- `Render Distance = N` означает радиус `N` секций, то есть примерно `N × 16` блоков во всех направлениях;
- `Simulation Distance` задаёт отдельную меньшую 3D-область активной симуляции;
- небо, солнце, луна и звёзды относятся ко всей планете, а локальный горизонт зависит от текущей грани;
- центральная область ядра недоступна, чтобы исключить точку с неопределённым направлением гравитации.

## Ветки

- `main` — стабильная основа репозитория и документация.
- `2.0` — новая архитектура кубического планетоида.

## Статус

Архитектура 2.0 зафиксирована. Реализация начинается с топологии шести граней, преобразований координат/направлений и 3D section loading.
